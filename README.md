# kimbsu00.github.io

Bilingual GitHub Pages portfolio for Kim ByeongSu, built with Vite and TypeScript.

## Commands

- `npm install`
- `npm run dev`
- `npm run typecheck`
- `npm test`
- `npm run build`

## Structure

- `/ko/`: Korean portfolio
- `/en/`: English portfolio
- `/ko/projects/:slug/`: Korean project detail pages
- `/en/projects/:slug/`: English project detail pages

Static route HTML files are generated automatically by `npm run generate:routes` before dev and build.
